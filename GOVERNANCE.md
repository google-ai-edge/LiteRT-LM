# Project governance

This repository is part of the Google-led LiteRT project and adopts the
[LiteRT project governance policy](https://github.com/google-ai-edge/LiteRT/blob/main/GOVERNANCE.md).

Google retains final authority over the upstream project's technical
direction, release policies, and project leadership, as described in that
policy.

The shared policy defines project lead and maintainer responsibilities,
technical decision-making, escalation, and governance changes.

Repository-specific code ownership is recorded in
[CODEOWNERS](.github/CODEOWNERS).

Contribution availability, contributor requirements, and development
workflows are described in [CONTRIBUTING.md](CONTRIBUTING.md). Adopting the
shared governance policy does not change those contribution policies.
